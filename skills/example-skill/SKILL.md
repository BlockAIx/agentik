# Example Skill

This is a placeholder skill demonstrating the agentik skills format.

Replace this file with domain-specific instructions that will be injected
into agent prompts when this skill is assigned to an agent.

## How skills work

- Place skill directories under `skills/` at the workspace root.
- Each skill directory must contain a `SKILL.md` file (this file).
- Optionally include a `skill.json` for metadata (name, description,
  recommended agents).
- Assign skills to agents per-project via the web UI Models tab or by
  editing `opencode.jsonc` directly.
